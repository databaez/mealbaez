# mealbaez
## Description
a web and mobile app that tracks your daily habits and activities and suggests meals tailored to your needs, along with the best times to eat them, so you can maintain your energy and focus throughout the day or week
## Key features
- Making a calendar to make it easier to see when you need to eat
- Creating a quiz that takes in users information
- Create a personalized plan based on users data
- Create a plan file to import to google calendar
- Linking grocery stores near you
- Set notification reminders
- Making the app social
- Make the user upload their meal to the app (checklist of what they need to eat)  and
- Update on the charts/daily goals
